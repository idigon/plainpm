---
name: status
description: Generate a status report for a specific plainpm project (or a portfolio summary across all projects). TRIGGER when the user asks for the status of a named project or stream — phrasings like "status of project <X>", "give me an update on <project>", "how is <project> going", "project status for <slug>", "portfolio status", or "status across all projects". SKIP for personal/today views like "what's on my plate" or "what should I work on" — those are dashboard requests handled by the slash commands `/today` and `/my-team`. SKIP for status changes to a single task (use `update`).
---

Read and follow the instructions in `prompts/commands/status.md` exactly.
